适合本地 coding agent 展示的独立 Python 小项目。

- QuixBugs 论文：https://doi.org/10.1145/3135932.3135941
- QuixBugs 官方仓库：https://github.com/jkoppel/QuixBugs
- Codex 修复研究：https://arxiv.org/abs/2111.03922
- 公开修复实验：https://github.com/ASSERT-KTH/quixbugs-experiment
